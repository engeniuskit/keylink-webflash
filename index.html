KeyLink V.1

Install the software on your KeyLink board.

  1. Use Chrome or Edge on a computer.
  2. Connect the board with a USB cable.
  3. Press the Install button and choose the board's COM port.
This browser cannot install. Use Chrome or Edge on a computer. Open this page over HTTPS.

If the board does not respond: hold BOOT, press RST once, release BOOT, then try again. The first install erases everything on the board, including saved rows and the Wi-Fi password.
