KeyLink V.1

Install the software on your KeyLink board.

ติดตั้งซอฟต์แวร์ลงในบอร์ด KeyLink ของคุณ

  1. Use Chrome or Edge on a computer.

    ใช้คอมพิวเตอร์และเปิดด้วย Chrome หรือ Edge

  2. Connect the board with a USB cable.

    เสียบบอร์ดด้วยสาย USB

  3. Press the Install button and choose the board's COM port.

    กดปุ่ม Install แล้วเลือกพอร์ต COM ของบอร์ด

This browser cannot install. Use Chrome or Edge on a computer.
เบราว์เซอร์นี้ติดตั้งไม่ได้ ให้ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ Open this page over HTTPS.
เปิดหน้านี้ผ่าน HTTPS

If the board does not respond: hold BOOT, press RST once, release BOOT, then try again.
ถ้าบอร์ดไม่ตอบสนอง: กดปุ่ม BOOT ค้างไว้ กด RST หนึ่งครั้ง แล้วปล่อย BOOT จากนั้นลองใหม่

The first install erases everything on the board, including saved rows and the Wi-Fi password.
การติดตั้งครั้งแรกจะลบข้อมูลทั้งหมดในบอร์ด รวมถึงการตั้งค่าปุ่มและรหัส Wi-Fi ที่บันทึกไว้
